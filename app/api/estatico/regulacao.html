O que cada ativo aceita

Por qual trilho o ativo vira garantia, onde o gravame é registrado, para qual produto serve e com que prazo. Tudo sai do catálogo regulatório da API (GET /v1/regulacao/matriz). O projeto simula o registro: não integra com a B3, com o Selic nem com a plataforma da Res. Conjunta 12.

O autor não é advogado; a modelagem jurídica precisa ser validada. Os LTVs são hipóteses de calibração, não padrão de mercado.
